Core Layout Law Mechanism: A card starts at the fit its author designed. If the column is narrow it gets wider; only when widening is exhausted does it degrade to a leaner fit, which trades a column for a row and re-lays its inside. That is the mechanism that guarantees nobody loses data to their screen size.
