# GROWTH.md — Execution Plan to Category Leadership (by MRR stage)

> "MRR" below = subscriptions + LTD amortized/24mo (PlatformRevenueService already computes this correctly). Assumption: launch quarter per ROADMAP.

## Stage 0 → $10K MRR (months 1–6) — "Do things that don't scale"
**Math:** ≈ 300 paying stores at $33 blended, or 150 subs + LTD cohort.
- Engine 1 — **AppSumo LTD (cash + installed base):** target 800–2,000 codes. Every LTD buyer is a review, a case study, and an add-on prospect.
- Engine 2 — **Founder-led PK migration concierge:** 20 stores/month personally migrated. Painful, perfect: every migration hardens the importer and yields an Urdu testimonial video.
- Engine 3 — **SEO comparison pages + free tools** (MARKETING §2) — planted now, compounds forever.
- Engine 4 — **Product Hunt + directories** — one-time spikes, permanent backlinks.
- Retention duty: weekly cohort review; personally call every churned store month 1–6 (the roadmap writes itself from these calls).
- **Kill criteria:** if trial→paid <10% after import concierge exists, stop all acquisition and fix activation — more traffic won't save a leaky funnel.

## $10K → $50K (months 6–14) — "Build the loops"
1. **Referral loop (build now, it's cheap):** give a month, get a month; shop owners cluster in markets — one bazaar = 40 referrals. In-product: "Powered by VenQore" on customer-facing receipts/invoice portal with referral link (invoice portal ships this stage — every invoice becomes an ad).
2. **Accountant loop:** CA dashboard-lite (read-only role) + 20% recurring → each CA brings 5–15 stores/yr. This is the highest-leverage B2B2B motion in this category.
3. **Reseller loop (PK/South Asia):** dealer program on the DRM/self-hosted rails; dealers earn install + AMC-style margin. Marg built a moat this way pre-internet; we do it with better software and web-based provisioning.
4. **Content flywheel:** hire PK content person ($400–700/mo) executing MARKETING calendar; founder only does YouTube demos + LinkedIn.
5. **Review flywheel:** automated in-app asks → 100+ G2/Capterra reviews → "High Performer" badges → directory traffic converts at 2–3× blog traffic.
6. First paid experiments ONLY after churn <2.5%: Google Ads on "loyverse alternative"-class keywords ($500/mo cap, kill at CAC>$250).

## $50K → $100K (months 14–20) — "Own the beachhead, open the second front"
- PK category ownership checkpoints: 3 dealer regions active, FBR-integration listed/known, 2 trade-association partnerships, Urdu UI shipped.
- Second market: pick ONE — UAE/Saudi (PK diaspora retailers, higher ARPU, same workflows) or Bangladesh/Nigeria (same price sensitivity, bigger volume). Localize pricing (geo engine ready), 10 pilot migrations, one local partner.
- Vertical packaging: pharmacy (batch/expiry compliance) or restaurant (KOT) — whichever pilot data supports; verticalized landing pages + 3 case studies each; price +$10/mo for vertical pack.
- Team: support lead + engineer hired (ROADMAP); add growth/content #2. Founder time: 50% product, 30% partnerships, 20% hiring.
- Platform play begins: public API + Zapier/Make connector → "works with" directory listings → integration SEO.

## $100K → $500K (months 20–36) — "Systematize"
- Sales team-of-two for mini-chains (inbound-fed); partner manager for CA/dealer channels.
- Marketplace expansion: Shopify + Daraz (critical for PK e-com) channels in VenSynQ; channel add-on revenue targeted ≥ 20% of MRR.
- Payments strategy decision point: embedded payments/local-rails partnership (JazzCash/Easypaisa rev-share) — the margin expander every POS eventually needs; negotiate from 5,000-merchant strength, not before.
- Community moat: annual VenQore retailer meetup PK (cheap, unheard-of in segment, unbeatable loyalty), certified-accountant program, template/report marketplace.
- Ops: SOC2-lite → SOC2; 99.9% SLO public; migrate hottest tenants DB read-replicas (H7/H8 groundwork done).

## $500K → $1M+ ARR → beyond
Options ranked by fit: (1) embedded payments residuals; (2) capital/lending data play (POS data = underwriting gold; partner, don't lend); (3) upmarket chains (50+ stores) with HQ consolidation; (4) geographic replication playbook (one new market per 2 quarters); (5) M&A of dying desktop-ERP install bases (buy a Marg dealer's book of business and migrate it).

## Growth principles (pin these)
1. One beachhead until $50K. 2. Loops > campaigns; every feature should feed a loop (receipts→referral, exports→accountant, sync→agency). 3. Churn is the growth ceiling — activation and support ARE growth spend. 4. LTD cash funds loops; never confuse it with product-market fit. 5. Distribution advantages (dealers, CAs, communities) compound; features get copied.
