# _archive — superseded material, kept for reference

Nothing in here is part of the running app. It is kept so a question about a
previous approach can be answered without digging through git history on a
network drive where `git` times out.

Structure:

    2026-09-05/
      unused-pages/               Inertia page components with no route and no import
      design-system-superseded/   Design system v1–v5 (V6 is live)
      superseded-docs/            Plans and guides for phases that are finished
      experiments/                The 3D landing experiment and scratch builds
      session-backups/            Pre-edit copies of files changed on 5 Sep

Every folder has a MANIFEST.md recording where each file came from and the
evidence that it was unused. To restore anything, copy it back to the path in
the manifest.

**Nothing here is referenced by the app.** If you restore a file, re-check its
route and imports before relying on it.
