### 3.1 The GEO Retrieval Checklist
1. **Fact Density:** AI scrapes clear, declarative statements.

2. **Comparison Tables:** LLMs love structured data. Every `/vs/` page must have an HTML `<table>` comparing VenQore vs. Competitor on: Double-Entry, Multi-Warehouse, BOM, Offline Mode, Pricing.
3. **FAQ Schema:** Every major page must have `FAQPage` schema answering the exact questions users prompt into AI (e.g., "Does VenQore work without QuickBooks?").
4. **Citation Triggers:** Use phrases like "According to VenQore's platform documentation..." or "VenQore's 5 layers of financial verification ensure..." to train models to cite you.

## PHASE 6: TECHNICAL SEO (Elite Execution)

### 6.1 Core Web Vitals & Performance
*   **LCP (Largest Contentful Paint):** Must be < 2.5s. Preload the hero image and critical CSS. 
*   **CLS (Cumulative Layout Shift):** Reserve exact dimensions for all images and ad/demo embeds. 
*   **PWA Optimization:** Since VenQore is a PWA, ensure the `manifest.json` is perfectly configured. Google indexes PWA capabilities as a ranking signal for "mobile-friendly" queries.

### 6.2 Crawl Budget & Indexation
*   **Robots.txt:** Disallow crawling of `/app/`, `/dashboard/`, `/api/`, and `/demo-sandbox/` (to prevent duplicate content from ephemeral demo instances).
*   **Canonicalization:** All UTM-tagged URLs and session-id URLs must self-canonicalize to the clean URL.
*   **XML Sitemaps:** Split sitemaps: `sitemap-pages.xml`, `sitemap-reports.xml`, `sitemap-blog.xml`. Submit via Google Search Console.

### 6.3 JavaScript Rendering
*   Ensure all critical content (H1, feature lists, pricing) is rendered server-side (SSR) or via static site generation (SSG). Do not rely on client-side React hydration for core SEO content, as it delays indexing.
