Layout Law

One formula governs both axes, so a card's height is computed exactly the way its width is. This is what makes generated dashboards safe: the AI picks a category, and the geometry is not its decision to get wrong.

The one law

size(n) = n × UNIT + (n−1) × GUTTER

Columns use UNIT = column width. Rows use UNIT = 64px. GUTTER = 24px on both axes. CSS Grid computes this natively from gap — which is why spacing must never come from a margin.

Why the gutter belongs to the pitch

Two stacked 1-row cards must line up with one 2-row card. If the gutter is added between cards, they do not: 64+24+64 = 152 against 128. A card that spans 2 rows spans across the gutter and absorbs it.

Format-to-fit

Measured in the shipping face (Space Grotesk 600, tabular, digit advance 0.62em) the worst-case 20-digit + 4-decimal value is 723px at metric size. No card can be that wide, so the premise inverts: a card is never sized to its number — the number formats to the card, and the exact value is always one hover away.

Band packing

A grid row band holds only cards of equal row-span. A taller card starts a new band rather than sitting beside shorter ones and leaving a hole. Leftover columns are handed back round-robin to cards below their category maximum, so a band is always flush. Cards never reorder — the author's sequence is the reading order on every screen.

The rules that survive from v2

One primary per viewTwo primaries is no primary. The mint glow is reserved for it.
One focal card per screenExactly one mint-filled card. Everything else is a white floater or the single ink card.
Never scale on hoverButtons lift 1px, cards 2px, sidebar items change colour only. The one legal scale-plus-clip is an image inside a fixed-ratio frame.
No meaning in colour aloneStatus = icon + word. Negative = sign + parentheses + danger. Passing = tick + word.
Tabular figures everywheretnum globally; money columns line up or the product looks careless.
Twelve z-index values, no morebase 0 raised 10 sticky 100 nav 200 rail 300 dropdown 400 drawer 500 modal 600 popover 700 tooltip 800 toast 900 command 1000
Clipping is not stackingIf something is invisible, look for an overflow:hidden ancestor before touching z-index. Portal tooltips and dropdowns to body.
Tables have no vertical linesThe point is that you replaced the spreadsheet.
Never animate a ledger figureCount-ups belong on marketing stats, not on a balance.
Ambient motion is marketing-onlyAbove the fold, ≥768px, and it stops under prefers-reduced-motion.
No emoji, everColour, shape and motion carry the playfulness.
