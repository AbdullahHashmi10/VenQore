# VenQore marketing UI kit

The public site in the v5 language, rebuilt from the landing page the founder liked
(`Hero Section/index.html` + `style.css`, screenshot `uploads/preview.webp`) and the
positioning in `Hero Section/VenQore-Copy-Bible.md`.

- `Hero.jsx` — glass nav + dark mint gradient hero with the prompt pill and
  example chips. Ambient gradient drift on `--vq-dur-amb`, reveals staggered 60ms.
- `Sections.jsx` — framed product preview (real components, not a screenshot),
  three-step mechanism, bento "moat" grid, correctness-wall proof stats, pricing
  with monthly/yearly tabs, mint CTA slab, ink footer.

Copy is lifted from the Copy Bible: category line "The AI ERP builder", the moat
sentence, "\$36 a month. No implementation fee." No invented logos, counts or
testimonials — the proof band uses only the claims the Bible marks as honest.
