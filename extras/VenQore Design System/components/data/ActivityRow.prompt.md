One-line: activity / transaction feed row for the dashboard right rail.

```jsx
<ActivityRow tone="in" title="Sale #SAL-R1-070826" meta="1 day ago" amount="+Rs 5,922.00"/>
<ActivityRow tone="out" title="Purchase #PUR-R1-2210" meta="1 week ago" amount="−Rs 1,700.00"/>
```

The sign is in the text as well as the colour — that is rule 4 of the system.
