# VenQore Feature Catalog — By Category

All 265 features sorted into categories. A feature appears in more than one category wherever it's genuinely useful in more than one context (e.g. a feature built for restaurants also belongs under Manufacturing if it deducts stock, or under Multi-Location if it deals with warehouses). No build-status labels here — this is a pure feature map. All report-type features are consolidated into one Reports category. There is no "Extras" category.

*All 265 features are represented above.
