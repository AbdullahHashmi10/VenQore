# VenQore Interactive Mockups & Live Theme Customizer

This folder contains the self-contained interactive mockups of the VenQore dashboards and reports, along with a live visual component customizer.

## Included Pages

1. **Overview (Old Main Dashboard)**: Replicates the first image (Performance, Outstanding, Net Profit, opportunities, and low stock).
2. **Executive Dashboard (Admin Panel)**: Replicates the second image (Pending items, Profit margin, Purchases trend, Inventory donut, Payment types distribution).
3. **Sales History**: Replicates the third image (Sales summary cards, Sales transactions table with searching and page actions).
4. **Products List**: Standard product data table with SKU, category, stock level, status tags, and search filters.
5. **Profit & Loss**: Replicates the fourth image (Left Reports Hub access navigation, Net Profit/Gross Profit/Expenses summaries, Income Statement visual rows, Revenue distribution donut).
6. **Sales Report**: Clean analytics screen showing daily sales trends and channels (POS, Woo, Amazon, eBay).

---

## Features

- **💡 Dark & Light Mode Toggles**: Flip the theme seamlessly via the moon/sun icon in the bottom-left sidebar.
- **🎨 Custom Presets**: Select one of five visual presets in the customizer panel to instantly load standard theme styles:
  - *Classic Dark (v1)*: Midnight blue dark theme from the original photos.
  - *VenQore v2 Dark*: Official design system v2 dark theme.
  - *VenQore v2 Light*: Official design system v2 light theme.
  - *Emerald POS*: Forest green & mint accent.
  - *Retro Amber*: Warm dark tones with amber accents.
- **🎛️ Individual Pickers**: Modify page background, card surfaces, text elements, lines, borders, active accents, and state colors (success/warning/danger).
- **📊 Real-time Chart Color Binding**: Charts dynamically sync their grids, borders, lines, and slices to color changes.
- **💻 Copy CSS Variables**: Click **"Copy theme variables CSS"** to export the custom theme straight to your clipboard.

## How to Open

Since this application is built with vanilla HTML/CSS and client-side JavaScript, you can open it directly in your browser:
1. Double-click the file `index.html` or drag-and-drop it into any web browser.
2. Click the floating **Palette (🎨)** icon in the sidebar to open the component customizer drawer.
3. Switch between dashboard screens using the sidebar rail icons.
