One-line: icon-only button for card headers, top bars and table row actions.

```jsx
<IconButton label="Notifications"><i className="ph ph-bell"/></IconButton>
<IconButton label="Filter" variant="ghost" active />
```

Radius is `--vq-r-md` (14px) — icon buttons are the one control that is not a pill, so they read as chrome rather than as actions. Hover changes colour + a 1px lift; never scale the glyph.
