02 · Principles

The laws that survive every version.

1 · No raw values in components

Colours, radii, z-index and other system values live in tokens. If a component needs a value that is not a token, the system is missing a token.

2 · Teal is the brand

Primary actions, focus, identity and active states use VenQore teal. Semantic colours and AI colour do not compete with the brand.

3 · Module colour is wayfinding

Module colour tells the user where they are. It belongs in chrome, navigation, headers, breadcrumbs and module accents — not inside financial data.

4 · Meaning is never colour alone

Negative values also get a minus sign/parentheses. Status gets an icon or dot and a word. Colour reinforces meaning; it does not carry it alone.

5 · Marketing may be expressive. Product may not.

Public pages can use ambient motion, expressive typography and a richer visual stage. The product prioritizes clarity, data, touch targets and controlled state feedback.

Hover contract

ButtonDarken one ramp step + lift 1px. Never scale.
CardLift 2px + elevation up one level.
Sidebar/nav itemBackground + text only. Never transform.
Standalone iconColour only. Never scale.
Avatar/chipRing appears. No scale.
Media thumbnailOnly legitimate scale+clip, inside a fixed-ratio frame.

Never animate

Financial figuresNo count-up on ledger/KPI financial values.
Layout after paintNo unexpected shifting caused by animation.
Ambient loops below foldMarketing ambient effects stop below the hero.
Reduced motionFreeze/replace decorative motion; preserve usability.
Blueprint exception: a staged module/blueprint animation can be slow and legible because it communicates how the system is assembled. That is product storytelling, not random UI motion.

13 · Data visualisation

Charts: one system, fixed colour order.

Library policy

Standardize on Recharts. Quarantine visx only where custom scales/zoom genuinely require it. Do not import d3 directly into ordinary chart components.

The original analysis identified three chart stacks: Recharts, many visx packages, and d3 pieces. That fragmentation creates different axes, tooltip behaviour and colour defaults.

Example series order

Fixed order · never randomly cycle the palette · ninth series folds into Other/small multiples.

RuleDecision
Series orderFixed slots; slot 1 is VenQore teal.
More than eight seriesFold into Other, facet, or redesign; never keep cycling colours.
Diverging chartsTwo hues + neutral grey midpoint. Never a saturated hue at zero.
Sequential dataOne hue light → dark; teal ramp is preferred for brand-aligned magnitude.
Dual-axis chartsAvoid unless the analytical case is truly unavoidable.
AnimationPrefer state transition; never count a financial KPI as if it were a game score.

15 · Applied

ReactBits — where it belongs.

Governing rule: ReactBits is primarily a marketing dependency. Inside the ERP it is allowed only when the animation communicates useful state or a very small set of approved interaction patterns.
AnimatedListLanding · business category picker

Keep. Good for choosing among categories. Cap visible items; keep keyboard navigation.

ShinyTextLanding · hero prompt

Keep once. It says “type here” and earns the shimmer.

FoldTextLanding · hero headline

Keep once on first paint. Never re-run on scroll.

LaserFlowLanding · footer watermark

Keep as a single page signature.

OptionWheelLanding · alternate picker

Choose one picker pattern, not two competing answers to the same question.

SplitTextApp

Remove. Animating headings inside an ERP adds motion without information.

DecryptedTextApp

Remove. Scrambling readable financial/UI text is hostile to clarity.

GooeyNavMarketing / navigation

Allowed when it genuinely improves the public navigation; do not import expressive effects into the dense app shell.

Skeleton / shimmerProduct loading

Approved because it communicates load state, not decoration.

17 · Ship it

The bugs and problems we found.

Critical · launch blocker

Customizer/debug drawer is exposed

Vorticity, splat force, pressure iterations and dye resolution controls appear on a public-facing page. Gate it behind ?debug=1 or remove it from production.

Critical

Template copy is still present

The design system analysis found placeholder/incorrect copy such as “VenQore — Design with AI”, “future of creativity” and unrelated design-generation language. Replace with the actual VenQore positioning and copy bible.

Critical

Dark-mode accent text contrast failure

#327882 used as text on dark backgrounds yields the documented 3.88:1 failure. Use #5DA5B0 for accent text on dark surfaces.

High

Sidebar hover clipping

overflow-hidden on the row + group-hover:scale-125 on the icon clips the icon and hover ring. Remove the transform/clip conflict.

High

Collapsed tooltip clipping

The tooltip sits inside an overflow-clipped parent even though it is positioned at left-full. Port it to body; z-index cannot escape the clipping ancestor.

High

Fluid canvas covers the gradient layer

The original build placed the canvas above the intended gradient. Restack the layers or convert the overlay into the controlling scrim. In the final master system, the mesh is now isolated as an optional card, not a global surface.

High

Dual-theme gradient inversion is hard to maintain

Switching text from white to black because the background changes from dark to light creates hand-tuned rules that will drift. Prefer a stable dark hero/light body marketing direction and a proper light/dark toggle inside the product.

High

Tailwind CDN on production

The audit identified the browser-loaded CDN build as a prototyping approach. Build and ship a real stylesheet.

Medium

Oversized navigation

The earlier public navigation was 96px tall. Bring the standard shell toward ~64px so the first content appears sooner.

Medium

Footer links are placeholders

Links pointing to # must be wired or removed before launch.

Systemic

31 z-index values

Codemod to named layers. Do not add another arbitrary z-index.

Systemic

~20 corner radii

Collapse to the final 12px / 20px / full visual vocabulary.

Systemic

184 hover-scale usages

Delete them except the explicitly approved media-thumbnail pattern.

Systemic

Multiple chart stacks

Standardize on Recharts. Quarantine visx. Avoid direct d3 imports in ordinary chart components.

Also keep in the fix list: focus-ring removal on the hero input, off-system indigo/purple classes, 700+ font weights, and any component that hardcodes colours/radii/z-index instead of tokens.

Final reference

What is now locked.

KEEP

Deep teal identity · energetic but controlled colour · big readable typography · italic serif signature · mono numbers · v3 avatar stacks · v4/v5 buttons · v5 card depth · active states · controlled spring motion · ReactBits mapping · marketing/product split.

CHANGE

Radius vocabulary → 12/20/full · desktop grid → 12 columns · tablet → 6 · mobile → 4 · AI signal → coral/rose instead of violet · module colours corrected so they cannot collide with semantic states.

REJECT

Tiny typography everywhere · huge consumer radii · global mesh backgrounds · violet-by-default AI · random indigo/purple UI · hover scale spam · count-up financial figures · arbitrary z-index/radius values · unconstrained dashboard resizing.

Mesh reminder: the v1 mesh is retained only as the optional visual card in section 10. It is deliberately not used as the default page background, dashboard background, card background, or repeated decorative layer.
