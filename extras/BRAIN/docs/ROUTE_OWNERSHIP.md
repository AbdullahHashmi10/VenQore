## Why this document exists

Hiding a nav item is not disabling a module. If the route still resolves, the module is still reachable by typing the URL — and the customer who finds that has found a bug in the thing you are selling as "your system, your modules".

So every route name gets one of four verdicts:

| Verdict | Meaning | Gate behaviour |
|---|---|---|
| **OWNED** | exactly one module claims it | blocked when that module is off |
| **SHARED** | several modules claim it | allowed if **any** owner is on |
| **ALWAYS-ON** | platform surface (`config/qore.php`) | never blocked |
| **UNCLAIMED** | nothing claims it | **always reachable** |
