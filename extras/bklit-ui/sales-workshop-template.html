One Sales card.
Several useful ways to read it.

Users keep control over size and presentation. We build a small shared system that adapts the content, instead of hand-designing every combination for every metric.

15 combinations. One reusable Sales definition.

For this example, Sales has 3 sizes × 5 presentations = 15 selectable combinations when the required data exists. Line, area, columns, and columns with a comparison line share the BKLIT composed-chart container. Target progress uses BKLIT’s Gauge. Loading and empty states are shared behavior, not additional bespoke designs.

One metric definition

Sales provides its label, currency, total, time series, previous-period total, and optional target. It declares which views its data supports.

Three layout recipes

Compact prioritizes a value and small plot. Standard adds axes and context. Wide adds a comparison series and supporting detail. Width stays responsive.

Shared chart components

This demo uses the actual downloaded BKLIT charts. Sales, purchases, and expenses can all use the same time-series component with different data.

“Target gauge” expresses progress toward a defined target. Compact uses a bar because a large dial is wasteful at that size. No target means this view is unavailable. A scalar total never becomes a fabricated trend.

What happens when there are 100 metrics?

We group metrics by the questions their data can answer. Each metric receives a definition and any required data adapter. It reuses the appropriate family; it does not receive its own copies of every chart.

The maintenance cost is the shared components, metric definitions, and any genuinely special cards. Testing still covers combinations: every shared renderer at each supported size and state, plus each metric’s data contract. Reuse reduces implementation work; it does not remove validation.

Keep customization. Constrain it to combinations that work.

Users choose a supported size and presentation, then reorder cards. The dashboard packs them into responsive rows. They do not need to locate an empty rectangle or stretch a card until it happens to look right.
